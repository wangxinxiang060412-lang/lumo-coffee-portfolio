# LUMO Coffee & Dessert Portfolio

An interactive UX case study and high-fidelity web prototype for the LUMO Coffee & Dessert WeChat Mini Program.

## Local preview

```bash
node server.js
```

Then open `http://127.0.0.1:8091`.

## Project structure

- `index.html` — UX case-study narrative and page structure
- `style.css` — portfolio visual system and responsive layout
- `app.js` — portfolio navigation and simulator bridge
- `miniapp-engine.js` — interactive Mini Program prototype engine
- `miniapp-data.js` — prototype fixture data
- `miniapp-simulator.css` — embedded Mini Program presentation styles
